# Plus Jakarta Sans

The app bundles unmodified static TrueType faces for Medium (500), SemiBold
(600), Bold (700), and ExtraBold (800). They load through the existing
`expo-font` dependency; no font CDN or additional font package is used at runtime.

- Original project: https://github.com/tokotype/PlusJakartaSans
- Distribution: https://github.com/expo/google-fonts/tree/4307f006860e648d05284aab525dccb1883fffba/font-packages/plus-jakarta-sans
- Retrieved: 2026-09-06
- License: SIL Open Font License 1.1, reproduced in `OFL.txt`.
- Source files: `<weight>/PlusJakartaSans_<weight>.ttf` from the pinned distribution above.
